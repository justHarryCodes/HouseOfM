# House of Mon (workspace)

This repository is a workspace wrapper. The House of Mon source code, documentation and deployment guide live in **[justHarryCodes/house-of-m](https://github.com/justHarryCodes/house-of-m)**.

House of Mon is a Telegram Mini App community network for Web3 builders, creators, founders and contributors. It has missions, reputation, rewards, governance, events and membership NFTs.
